Projets

Installation et configuration de VMware ESXi

Mise en place d'un environnement virtualisé pour optimiser les ressources informatiques :

  • Installation de VMware ESXi sur un serveur physique pour créer un hyperviseur.
  • Création et gestion de machines virtuelles pour différents scénarios (Windows Server, Debian, PfSense).
  • Configuration des paramètres réseau pour permettre une communication entre les machines virtuelles.

Configuration de PfSense

Déploiement d'un pare-feu et routeur pour sécuriser l'infrastructure réseau :

  • Installation de PfSense sur une machine virtuelle via VMware ESXi.
  • Configuration des interfaces réseau (WAN et LAN) pour gérer le trafic entrant et sortant.
  • Création de règles de pare-feu pour filtrer les accès et protéger les ressources internes.
  • Mise en place d'un serveur VPN pour des connexions distantes sécurisées.

Configuration de Debian

Mise en place d'un serveur Debian pour des environnements réseau :

  • Installation de Debian sur une machine virtuelle via VMware ESXi.
  • Configuration de services réseau tels que SSH pour un accès distant sécurisé.
  • Gestion des utilisateurs et des droits avec des outils Linux (sudo, chmod, etc.).
  • Installation et configuration d'un serveur web (Apache) pour héberger des sites web.

Configuration de Windows Server 2022/2025

Déploiement et administration de serveurs Windows dans un environnement virtualisé :

  • Installation de Windows Server 2022/2025 sur une machine virtuelle via VMware ESXi.
  • Configuration des rôles principaux : Active Directory, DNS, et DHCP.
  • Mise en place et gestion des utilisateurs, groupes, et GPOs (Group Policy Objects).
  • Gestion des sauvegardes et des restaurations pour assurer la continuité des services.
